Promise-Based Dialogs

Info, warning, danger, confirm, prompt, save, open, plus custom modals, side drawers, and a Web3 transaction guard.

Deterministic Memory Engine

XSS

Security By Default

Store

Web3

Secure Web3 interfaces, hardened by default.

Prestige Web UI is optimized for secure web3, transaction confirmation guards, secret hygiene, and defense-in-depth XSS protections built into the shell itself.

Guard

Transaction Confirmation Guard

web3TransactionGuard() renders a high-security overlay on its own z-plane, a MutationObserver rejects any injected DOM tampering before approval.

safe

Clickjacking Defense

isElementVisuallySafe() verifies the confirm button is the actual top-most element at the click point before a transaction passes.

secrets

Secret Zeroing

ownSecret() tracks credential buffers and zero-fills them on disposal, no private key or seed survives in memory after teardown.

credentials

Credential Guard

createStore() refuses to persist keys named token, secret, password, session, or cookie, credentials never leak into localStorage.

bigint

BigInt Precision

Transaction values are always bigint in wei, never floats, so amounts survive at full precision across every path.

XSS

XSS Defense-in-Depth

Text-first rendering, a strict TreeWalker sanitizer, URL schemes allowlist, and app-ID validation guard every input surface.

Backend · TypeScript

Reliability and security, enforced by the compiler.

Prestige UI's backend is authored entirely in strict TypeScript. The compiler rejects whole classes of bugs before they ship, and the build emits standalone, zero-dependency JavaScript, so the shell is dependable and secure by construction.

Compiler-enforced reliability

Strict mode gates, noImplicitAny, strictNullChecks, exactOptionalPropertyTypes, noUnusedLocals, make the compiler reject bugs at build time, not runtime.

Secure by default

Text-first rendering, a TreeWalker HTML sanitizer, URL scheme allowlists, and app-ID validation guard every input surface against XSS.

Deterministic memory

DisposalStack LIFO teardown and Owned affine handles, timers, sockets, and listeners are reclaimed the moment a window closes.

Zero-dependency output

TypeScript never ships to your users. The backend compiles to pure vanilla JS + CSS, nothing to install, audit, or vendor at runtime.

typescript/tsconfig.json + AppManifest
// Strict backend contract, ships as plain JS + CSS
{
  "compilerOptions": {
    "strict": true,
    "noImplicitAny": true,
    "strictNullChecks": true,
    "exactOptionalPropertyTypes": true,
    "noUnusedLocals": true,
    "target": "ES2022"
  }
}

// Typed contract shared by every registered app
interface AppManifest {
  title: string;
  icon: string;
  placement: 'dock' | 'topdock' | 'hidden' | 'both';
  content: (appId: string) => HTMLElement;
}

Quick Start

Live in seconds.

Two tags, shell markup, and one line of JavaScript. No build step, no framework.

index.html
<!-- 1. Two tags -->
<link rel="stylesheet" href="dist/prestige.css">
<script src="dist/prestige.umd.js" defer></script>

<!-- 2. Declare the shell -->
<body class="desktop-body">
  <header class="menubar">
    <span class="menubar-app">My App</span>
    <span class="menubar-clock" id="menubar-clock"></span>
  </header>
  <main class="desktop-canvas" id="desktop-canvas"></main>
  <nav class="dock" id="dock"></nav>
</body>
// 3. Initialize
document.addEventListener('DOMContentLoaded', () => {
  const os = new Prestige({
    search: true,         // Ctrl+Space spotlight
    dock: true,
    topdock: true,
    snap: true,           // magnet snapping
    shakeToMinimize: true,
    session: true,        // persist layout
  });

  os.init();
  renderIcons();            // hydrate SVG icons

  // React to the shell
  os.on('window:open', ({ section, win }) => {
    console.log(`Opened ${section}`, win);
  });
});
os.registerApp('analytics', {
  title: 'Analytics',
  icon: 'chart-no-axes-column',
  c1: '#fbe482',
  c2: '#000000',
  placement: 'dock',      // 'dock' | 'topdock' | 'hidden' | 'both'
  w: 900, h: 620,

  // DOM nodes render as-is; strings render as text.
  content: (appId, label, icon) =>
    createCard('Revenue', createStatCard('99.9%', 'Uptime')),
});

// Open it
os.openWindow('analytics');
